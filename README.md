# hwp2LLM
The Ultimate HWP to TXT/PDF Batch Converter for AI

- hwp2LLM은 대용량 HWP / HWPX 한글 문서를 PDF와 TXT 파일로 동시에 일괄 변환하는 데이터 전처리 도구입니다. 복잡한 한글 문서 내부의 텍스트 데이터를 AI 가공에 적합한 형태로 안전하게 추출합니다.

## 🎯 개발 취지
- 한국어 데이터의 핵심을 이루는 한글(HWP) 문서를 LLM(대형 언어 모델) 및 AI 파이프라인에서 즉시 활용할 수 있도록 돕기 위해 개발되었습니다. 텍스트 추출과 원본 확인용 PDF 변환을 동시에 수행하여 AI 데이터 준비 시간을 크게 단축합니다. 본 앱을 사용해서 많은 사용자들이 다양한 연구와 교육에 도움을 받기를 바랍니다.

## ✨ 핵심 기능
1. PDF & TXT 동시 변환 (Dual Export): 문서 1개당 텍스트 분석용 TXT와 양식 확인용 PDF를 함께 생성합니다.
2. 대용량 일괄 처리 (Batch Processing): 수십만 개의 문서를 중단 없이 안정적으로 자동 변환합니다.
3. 깨진 파일 등 예외 처리 : 중복 변환 자동 방지(Skip System) 및 한글 COM 프로세스 멈춤(Hang) 방지 타임아웃을 탑재했습니다.

## 💡 주요 활용처
- LLM & RAG 데이터 파이프라인: Vector DB 인덱싱, RAG(검색 증강 생성) 구축, AI 모델 임베딩/파인튜닝 데이터 전처리
- 생성형 AI 문서 분석: Grok, ChatGPT, Claude 등 생성형 AI 서비스에 TXT 파일들을 직접 업로드하여 데이터 요약, 정보 추출 및 학술 분석 수행
